# คู่มือเริ่มต้นใช้งาน (สำหรับคนที่ไม่เคยทำมาก่อน)

เอกสารนี้บอกทีละขั้นตอนว่าต้องกดอะไร ที่ไหน ไม่ต้องมีความรู้เรื่องเขียนโปรแกรมมาก่อน
แบ่งเป็น 3 ช่วง ทำเรียงกันได้เรื่อยๆ ไม่ต้องรีบทำให้เสร็จวันเดียว

- **ช่วงที่ 1** — ลองเปิดเว็บดูก่อน (5 นาที ไม่ต้องตั้งค่าอะไรเลย)
- **ช่วงที่ 2** — ต่อฐานข้อมูลจริงผ่าน Google Sheet + Drive + Apps Script (ให้หลายคนใช้ร่วมกันได้)
- **ช่วงที่ 3** — ตั้งค่า AppSheet เป็นแอพมือถือ (ทางเลือก ทำทีหลังก็ได้)

---

## ช่วงที่ 1 — ลองเปิดเว็บดูก่อน

ตอนนี้เว็บใช้งานได้เลยทันที โดยข้อมูลจะถูกเก็บไว้ใน**เบราว์เซอร์เครื่องเดียวที่เปิด**
(เทคนิคเรียกว่า localStorage) — เหมาะสำหรับลองเล่น ยังไม่ใช่ฐานข้อมูลกลางที่ทุกคนเห็นร่วมกัน

1. แตกไฟล์ `HILLKOFF-WEB.zip` ที่ได้รับ ให้ได้โฟลเดอร์ชื่อ `HILLKOFF-WEB`
2. ติดตั้งโปรแกรม **Visual Studio Code** (ฟรี) จาก https://code.visualstudio.com/ ถ้ายังไม่มี
3. เปิด VS Code → **File → Open Folder** → เลือกโฟลเดอร์ `HILLKOFF-WEB`
4. ทางซ้ายจะเห็นรายการไฟล์ → ไปที่ **Extensions** (ไอคอนสี่เหลี่ยมเรียงกัน แถบซ้ายสุด)
   → พิมพ์ค้นหา "Live Server" (ผู้พัฒนา Ritwick Dey) → กด **Install**
5. กลับไปที่รายการไฟล์ → เปิดโฟลเดอร์ `html` → คลิกขวาที่ `index.html`
   → เลือก **Open with Live Server**
6. เบราว์เซอร์จะเปิดขึ้นมาเองที่หน้า Dashboard — ลองกดปุ่ม "เพิ่มเครื่องจักร" กรอกข้อมูล
   ลองดูจนครบทุกหน้าได้เลย

> ถ้าปิดเบราว์เซอร์แล้วเปิดใหม่ ข้อมูลที่เพิ่มไว้จะยังอยู่ (เพราะเก็บใน localStorage ของ
> เบราว์เซอร์เครื่องนั้น) แต่ถ้าเปิดจากเครื่องอื่นจะไม่เห็นข้อมูลเดียวกัน — นี่คือเหตุผลที่ต้องทำ
> ช่วงที่ 2 ถ้าต้องการให้ทีมใช้ร่วมกันจริง

## ช่วงที่ 2 — ต่อฐานข้อมูลจริง (Google Sheet + Drive + Apps Script)

ทำตามลำดับ B1 → B5 ห้ามข้าม เพราะแต่ละขั้นต้องใช้ค่าที่ได้จากขั้นก่อนหน้า

### B1. สร้าง Google Sheet

1. ไปที่ https://sheets.google.com → คลิก **"+ Blank"** เพื่อสร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ (คลิกที่คำว่า "Untitled spreadsheet" มุมบนซ้าย) เป็น เช่น `HILLKOFF Database`
3. ที่แท็บด้านล่าง (ตอนนี้มีแท็บเดียวชื่อ "Sheet1") → คลิกขวา → **Rename** → เปลี่ยนชื่อเป็น `Machine`
4. คลิก **"+"** ที่มุมล่างซ้ายเพื่อเพิ่มแท็บใหม่ ทำซ้ำจนได้ครบ 5 แท็บ ชื่อตรงตามนี้ **(ตัวสะกดต้อง
   ตรงเป๊ะ ตัวพิมพ์เล็ก/ใหญ่มีผล)**:
   - `Machine`
   - `Specification`
   - `Parts`
   - `Images`
   - `Documents`
5. ในแต่ละแท็บ ให้พิมพ์หัวตารางลงในแถวที่ 1 (แต่ละคำในหนึ่งช่อง A1, B1, C1, ... ไล่ไปทางขวา)
   ตามนี้:

   **แท็บ Machine** — แถว 1 พิมพ์: `MachineID | Category | Name | Brand | Model | Type | Description | CoverImageURL | CreatedAt | UpdatedAt`

   **แท็บ Specification** — แถว 1 พิมพ์: `MachineID | Voltage | Power | Frequency | CoffeeBoiler | SteamBoiler | Pump | Group | PID | Display | Dimension | Weight | WaterTank`

   **แท็บ Parts** — แถว 1 พิมพ์: `PartID | MachineID | Name | Brand | Model | Note | ImageURL`

   **แท็บ Images** — แถว 1 พิมพ์: `ImageID | MachineID | Section | GroupKey | ImageURL | UploadedAt`

   **แท็บ Documents** — แถว 1 พิมพ์: `DocumentID | MachineID | DocType | FileName | FileURL | UploadedAt`

   วิธีที่เร็วที่สุด: พิมพ์คำแรกในช่อง A1 แล้วกด Tab เพื่อไปช่องถัดไปในแถวเดียวกัน
   พิมพ์ทีละคำจนครบ (เครื่องหมาย `|` ด้านบนเป็นแค่ตัวคั่นให้อ่านง่าย ไม่ต้องพิมพ์)

6. ดูที่ URL ด้านบนเบราว์เซอร์ จะมีรูปแบบ
   `https://docs.google.com/spreadsheets/d/AAAAAAAAAAAAAAAAAA/edit`
   → คัดลอกส่วนตัวอักษร/ตัวเลขยาวๆ ระหว่าง `/d/` กับ `/edit` — นี่คือ **Sheet ID**
   เก็บไว้ใช้ในขั้น B3

### B2. สร้างโฟลเดอร์ Google Drive

1. ไปที่ https://drive.google.com → คลิก **"+ New" → "New folder"**
2. ตั้งชื่อ เช่น `HILLKOFF Machines` → กด Create
3. ดับเบิลคลิกเข้าไปในโฟลเดอร์ที่สร้าง ดู URL จะเป็นแบบ
   `https://drive.google.com/drive/folders/BBBBBBBBBBBBBBBB`
   → คัดลอกตัวอักษร/ตัวเลขท้าย URL หลัง `/folders/` — นี่คือ **Drive Folder ID**
   เก็บไว้ใช้ในขั้น B3

### B3. วางโค้ด Apps Script

1. กลับไปที่ Google Sheet ที่สร้างไว้ (`HILLKOFF Database`)
2. เมนูด้านบน คลิก **Extensions → Apps Script**
   (ถ้าเมนูภาษาไทย จะเป็น **ส่วนขยาย → Apps Script**)
3. จะเปิดแท็บใหม่ เห็นไฟล์ `Code.gs` มีโค้ดเปล่าๆ อยู่ (`function myFunction() {}`)
   → คลิกเลือกโค้ดทั้งหมดในนั้น (Ctrl+A) แล้วลบทิ้ง (Delete)
4. เปิดไฟล์ `appscript/Code.gs` จากโฟลเดอร์ที่ได้รับ (เปิดด้วย Notepad, VS Code หรือโปรแกรม
   แก้ไขข้อความอะไรก็ได้) → คัดลอกโค้ดทั้งหมด (Ctrl+A แล้ว Ctrl+C)
5. กลับไปที่แท็บ Apps Script ที่ลบโค้ดไปแล้ว → วาง (Ctrl+V)
6. หาบรรทัดใกล้ๆ ด้านบนที่เขียนว่า:
   ```
   const SHEET_ID = 'YOUR_SPREADSHEET_ID_HERE';
   const DRIVE_ROOT_FOLDER_ID = 'YOUR_DRIVE_ROOT_FOLDER_ID_HERE';
   ```
   → แก้ `YOUR_SPREADSHEET_ID_HERE` เป็น Sheet ID ที่คัดลอกไว้จาก B1
   → แก้ `YOUR_DRIVE_ROOT_FOLDER_ID_HERE` เป็น Drive Folder ID ที่คัดลอกไว้จาก B2
   (ต้องอยู่ในเครื่องหมายคำพูด `' '` เหมือนเดิม เช่น `const SHEET_ID = '1a2B3c...';`)
7. กด **Ctrl+S** (หรือคลิกไอคอนรูปแผ่นดิสก์มุมบนซ้าย) เพื่อบันทึก
   → อาจมีให้ตั้งชื่อโปรเจกต์ ตั้งชื่ออะไรก็ได้ เช่น `HILLKOFF Backend`

### B4. เผยแพร่เป็น Web App

1. มุมบนขวาของหน้า Apps Script → คลิกปุ่ม **Deploy → New deployment**
2. จะมีหน้าต่างเด้งขึ้นมา → คลิกไอคอนรูปเฟือง ⚙️ ข้างคำว่า "Select type"
   → เลือก **Web app**
3. กรอกข้อมูล:
   - Description: ใส่อะไรก็ได้ เช่น `v1`
   - Execute as: เลือก **Me** (บัญชีของคุณ)
   - Who has access: เลือก **Anyone within [ชื่อองค์กรของคุณ]** ถ้ามี Google Workspace
     ขององค์กร (แนะนำ เพราะจำกัดเฉพาะคนในทีม) หรือถ้าไม่มี Workspace องค์กร ให้เลือก
     **Anyone** (ข้อมูลจะเข้าถึงได้ผ่านลิงก์นี้ — ควรเก็บลิงก์ไว้เป็นความลับ)
4. กด **Deploy**
5. จะมีหน้าต่างขอสิทธิ์ (Authorize access) → เลือกบัญชี Google ของคุณ
   → อาจเจอคำเตือน **"Google hasn't verified this app"** เพราะเป็นโค้ดที่เราเขียนเอง ไม่ใช่แอพ
   ที่ขึ้นทะเบียนสาธารณะ → คลิก **Advanced** (ลิงก์เล็กๆ) → คลิก **Go to [ชื่อโปรเจกต์] (unsafe)**
   → คลิก **Allow** — ขั้นตอนนี้ปลอดภัย เพราะเรากำลังอนุญาตให้โค้ดของเราเองเข้าถึง Sheet/Drive
   ของเราเอง ไม่ได้ส่งข้อมูลให้บุคคลภายนอก
6. หลัง Deploy สำเร็จ จะเห็นกล่อง **Web app URL** ยาวๆ ขึ้นต้นด้วย
   `https://script.google.com/macros/s/.../exec`
   → คัดลอกเก็บไว้ นี่คือ**ที่อยู่ (URL) ของฐานข้อมูล** ที่เว็บไซต์จะเรียกใช้

### B5. เชื่อมเว็บไซต์เข้ากับฐานข้อมูลจริง

ขั้นนี้ต้องแก้โค้ดอีกเล็กน้อย มี 2 ทางเลือก:

**ทางเลือก ก) ให้ผมช่วยแก้ให้** (แนะนำถ้าไม่อยากแตะโค้ดเอง)
ส่ง **Web app URL** จากข้อ B4.6 มาในแชทนี้ (และถ้าสะดวก ส่ง Sheet ID กับ Drive Folder ID
มาด้วย) แล้วบอกผมว่า "ช่วยต่อเว็บเข้ากับ backend ให้หน่อย" — ผมจะแก้ไฟล์
`js/api-client.js` และจุดที่เกี่ยวข้องใน `machines-data.js` / `dashboard.js` /
`machine-detail.js` / `add-machine.js` ให้ดึงข้อมูลจริงจาก Google Sheet แทน
localStorage แล้วส่งไฟล์ที่แก้แล้วกลับมาให้ดาวน์โหลดใหม่

**ทางเลือก ข) ทำเอง** — เปิดไฟล์ `docs/BACKEND-INTEGRATION.md` หัวข้อ
"Wiring the frontend" มีบอกทีละจุดว่าต้องแก้บรรทัดไหนในไฟล์ไหน

## ช่วงที่ 3 — ตั้งค่า AppSheet (ทางเลือก ทำทีหลังก็ได้)

ทำได้หลังช่วงที่ 2 เสร็จแล้ว (ต้องมี Google Sheet ที่มีข้อมูลตาม B1 ก่อน)

1. ไปที่ https://appsheet.com → คลิก **Sign in with Google**
2. คลิก **Create → App → Start with existing data**
3. เลือก **Google Sheets** → ล็อกอินและเลือกไฟล์ `HILLKOFF Database` ที่สร้างไว้ในขั้น B1
4. AppSheet จะดึงทั้ง 5 แท็บมาเป็นตารางให้อัตโนมัติ
5. ไปที่เมนูซ้าย **Data → Columns** ของแต่ละตาราง แล้วปรับตามที่ระบุไว้ใน
   `docs/APPSHEET-DESIGN.md` (กำหนด key column, ชนิดข้อมูล Enum/Image/Ref ฯลฯ —
   มีตารางสรุปให้ทำตามได้เลยทีละบรรทัด)
6. ไปที่ **UX → Views** เพื่อสร้างหน้าจอ Dashboard / Machine Detail ตามที่เอกสารแนะนำ
7. ไปที่ **Users → Security** เพื่อจำกัดให้เฉพาะอีเมลในองค์กรเข้าใช้แอพได้

รายละเอียดทุกขั้นตอน (ตาราง คอลัมน์ ควรตั้งชนิดอะไร, ควรสร้าง view แบบไหน) อยู่ครบใน
`docs/APPSHEET-DESIGN.md` แล้ว — ถ้าติดขั้นไหนถามในแชทได้เลย จะอธิบายเพิ่มเป็นจุดๆ ให้

## ช่วงที่ 4 — จำกัดสิทธิ์ดูข้อมูล Internal Structure (เอาออกไปก่อนแล้ว)

เคยมีฟีเจอร์นี้ (ให้กรอกรหัสผ่านก่อนดูแท็บ Internal Structure) แต่เอาออกไปแล้ว
ตอนนี้ทุกแท็บดูได้ตามปกติหมด ไม่ต้องกรอกอะไรเลย ถ้าอยากได้กลับมาในอนาคต
บอกได้เลย ทำใหม่ได้ไม่ยาก

## สรุปว่าตอนนี้ควรทำอะไรก่อน

1. ลองช่วงที่ 1 ก่อน (เปิดเว็บดู) ให้มั่นใจว่าหน้าตา/การใช้งานตรงกับที่ต้องการ
2. ถ้าโอเคแล้ว ค่อยทำช่วงที่ 2 (B1 → B4 เป็นสิ่งที่ต้องกดในเว็บ Google เอง ทำได้แม้ไม่มีพื้นฐาน
   เขียนโปรแกรม) แล้วส่ง Web app URL กลับมาให้ผมต่อโค้ดให้ในขั้น B5
3. ช่วงที่ 3 (AppSheet) ทำเมื่อไหร่ก็ได้ ไม่กระทบกับเว็บส่วนอื่นที่ใช้อยู่แล้ว
